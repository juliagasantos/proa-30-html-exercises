Caça aos Erros de CSS

Nesta atividade, foram criados erros propositalmente em um arquivo SCSS para praticar a identificação e correção de problemas de sintaxe.

O que foi praticado?

  • Ausência de ponto e vírgula
  • Ausência de chave
  • Propriedade escrita incorretamente
  • Valor inválido
  • Seletor incorreto
  • Erro de sintaxe

Exemplos de erros

Erro 1 — Ausência de ;

color: var(--primary-light)
font-size: 2em;

A propriedade color está sem ponto e vírgula.

Erro 2 — Propriedade incorreta

colr: red;

A propriedade correta é color.

Erro 3 — Valor inválido

font-size: grande;

O valor utilizado não é válido para font-size.

Erro 4 — Seletor incorreto

titulo {
    color: white;
}

O seletor não corresponde a nenhum elemento chamado titulo.

Erro 5 — Chave ausente

.card {
    padding: 1em;
    color: white;

A chave de fechamento foi esquecida.

Erro 6 — Unidade inválida

margin: 20abc;

A unidade utilizada não existe no CSS.
